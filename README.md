# KODA 일일동향 뉴스 포털

## 현재 반영된 원본
`일동향.xlsx`의 시트1을 읽어 2026-09-18부터 2026-11-26까지 46일분을 반영했습니다.
- 11개 열: 날짜, 제목, 썸네일이미지, 썸네일이미지링크, 썸네일 한글제목, [A] 회원사 소식, [B] 정책 및 부동산개발업계 동향, [C] 기타 소식, 대표 4개 기사 한글 제목1~3
- 뉴스 항목 544건을 원문 제목/출처/URL 기준으로 정리했습니다.
- 날짜별 대표 기사 및 썸네일 링크도 함께 반영했습니다.
- 기사 본문은 복사하지 않고 원문 링크로 연결합니다.

## 파일
- `index.html`: 누구나 볼 수 있는 공개 뉴스 포털
- `admin.html`: 협회 담당자용 뉴스 등록/수정/삭제 및 JSON 내보내기
- `app.js`: 날짜별·분야별·검색 기능, 공개 CSV 연결
- `news.json`: 첨부 엑셀에서 변환한 날짜별 46일 자료
- `style.css`: KODA 네이비/화이트 디자인, 반응형 레이아웃
- `koda-logo.png`, `koda-symbol.png`: 협회 로고

## Google Sheets 연결
`app.js`에는 기존 공개 CSV 주소가 설정되어 있습니다.
브라우저에서 CSV 읽기가 허용되면 페이지가 구글 시트 최신 자료를 먼저 읽습니다. 연결이 되지 않거나 CSV 형식이 예상과 다르면 첨부해 주신 엑셀에서 만든 `news.json`으로 자동 대체합니다.
시트 열은 실제 엑셀의 11개 열 순서에 맞춰 읽습니다. 시트에 새 날짜 행을 추가할 때도 같은 열 순서를 유지해 주세요.

## GitHub Pages 배포
1. GitHub에서 새 저장소(예: `koda-daily-news`)를 생성합니다.
2. 이 폴더 안의 모든 파일을 저장소 최상위(root)에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
4. Branch `main`, Folder `/(root)`를 선택하고 저장합니다.
5. 배포 주소는 `https://깃허브계정.github.io/koda-daily-news/` 형태입니다.

## 관리자 사용
1. 공개 사이트 주소 뒤에 `admin.html`을 붙여 관리자 페이지를 엽니다.
2. 게시일, 분야, 제목, 출처, 기사 URL을 입력해 뉴스 등록/수정/삭제합니다.
3. `news.json 다운로드`를 누릅니다.
4. 내려받은 `news.json`을 GitHub 저장소의 기존 `news.json`과 교체해 커밋합니다.
5. 공개 페이지가 새 데이터를 표시합니다.

주의: GitHub Pages는 정적 호스팅이므로 관리자 페이지의 저장은 현재 브라우저 안에서만 반영됩니다. 모든 방문자에게 공개하려면 내보낸 JSON을 GitHub에 커밋해야 합니다. 관리자 페이지 자체에는 로그인/권한 인증이 없습니다. GitHub 토큰을 프론트엔드 코드에 넣지 마세요.

## 일일동향 원본 문서
엑셀의 B열은 일일동향보고 제목, C열은 썸네일 이미지 파일 링크, D열은 썸네일 클릭 시 연결되는 기사 링크입니다. 별도 PDF/보고서 파일 링크 열은 원본에 포함되어 있지 않습니다.


## 실시간 구글 시트 연동 (개선)
- `app.js`에서 제공된 공개 CSV URL을 직접 읽습니다.
- 실제 엑셀에서 확인한 11개 열 순서(A~K)를 기준으로 파싱합니다.
- 날짜 `26.11.26(목)` 형식을 인식합니다.
- F~H열의 각 뉴스 항목은 제목과 다음 줄의 원문 URL을 짝지어 표시합니다.
- I~K열 대표 기사 제목을 주요 뉴스로 강조합니다.
- 구글 시트에서 내용을 수정하고 웹에 게시된 CSV가 갱신되면 페이지 새로고침 시 최신 자료를 읽습니다.
- 브라우저가 Google CSV 응답을 CORS로 차단하거나 게시 권한이 바뀌면 연결 실패 메시지가 표시됩니다.


## 연결 오류 및 이미지 표시 보완
- 구글 시트 CSV를 먼저 불러오고, 실패하면 news.json의 기존 저장 자료를 자동 표시합니다. 상단 상태에 실시간 연결인지 저장 자료 표시인지 구분해 안내합니다.
- 썸네일은 C열의 Google Drive 공유 파일을 이미지 표시용 주소로 변환합니다. Drive 파일 공유 권한을 '링크가 있는 모든 사용자-뷰어'로 설정해야 외부 방문자에게 표시됩니다.
- 기사 제목을 누르면 해당 원문 URL로 이동합니다.
- 페이지 하단 날짜 이동은 최신 5개 날짜를 먼저 보여주며 화살표로 이전/다음 날짜 묶음을 넘깁니다.
- 브라우저에서 Google이 CSV 요청을 차단하는 경우 상단에 저장 자료 표시 상태가 나타납니다. 이는 실시간 연결이 성공한 것이 아니며, 실제 실시간 연결을 위해서는 게시된 CSV URL과 공개 권한을 점검해야 합니다.
